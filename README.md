# Golden Goose

Project workspace for Golden Goose.

For the complete flow in one image, open [Kivi's single-page architecture SVG](KIVI_COMPLETE_FLOW.svg). It shows both Kivi modes, internal learning/recall/control steps, directional exchanges and the shared product database.

For a compact editable mentor presentation, use the [Excalidraw board preview](mentor-excalidraw/index.html), [six-frame editable board](mentor-excalidraw/Golden-Goose-Mentor-Board.excalidraw) or [overview-only drawing](mentor-excalidraw/Golden-Goose-Compact-Overview.excalidraw). These focus on regular Kivi versus Hey Kivi, shared database/memory structure, CRUD, safeguards, technology rationale and next work.

For a mentor discussion, open the [SVG image collection](mentor-svg/index.html): one overall architecture and 15 detailed process/feature diagrams, with examples, open decisions and remaining work. The [downloadable SVG pack](mentor-svg/Golden-Goose-Mentor-SVG-Pack.zip) includes a reading order and assignment coverage checklist.

Start with the [concise architecture guide](ARCHITECTURE_GUIDE.html): one small overview, nine separate process explanations and a clear next-work sequence. The [separate reference files](guide/README.md) let you open or link to just the topic you need.

[ARCHITECTURE.md](ARCHITECTURE.md) remains the consolidated project plan and reviewed v1 technical baseline. It brings together the conversation's product intent, assignment requirements, tech stack, twelve memory categories, storage and workflow contracts, research decisions, evaluation, submission checklist and open choices. It governs technical decisions and takes precedence over older notes. The guide explains this baseline; it does not replace it.

The next stage is user-experience refinement, then a working CLI and the final normal-user interface. The application, migrations, approximately 500-record corpus, live model integration and semantic benchmarks are not built yet. Model and frontend details remain explicitly marked as open or proposed in the plan.

The [research dossier](research/README.md) contains supporting sources and independent reviews. An [isolated storage-contract experiment](research/validation/REVIEW.md) passes 12 checks; this is not a working Kivi application or a model/performance benchmark.
